### View contract
Each view module exports `export default async function view(ctx)`. ctx = { root (HTMLElement to render into, initially empty), path, params (route params, e.g. {id}), query (URLSearchParams), route, navigate(path, {replace}), setTitle(title), isActive() (becomes false once the user navigates away — check it after every await before touching the DOM), onCleanup(fn) (register teardown: intervals, store listeners), refresh() (re-render the current route) }. main.js shows a loading spinner until the view renders and an error state if it throws. Internal links are plain `<a href="/path">` (main.js intercepts them).
